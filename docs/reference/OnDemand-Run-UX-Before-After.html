Three prompt addenda for the wording

Step 1 works with today's prompts. These text-only additions make the copy read like an agent. No schema, key or event changes. Switch between “1 · UI only” and “2 · + prompt addenda” in the replay to see the difference.

Planner

Writes planning_output, forwarded as plan_created.queryPlan

  • objective becomes one first-person sentence, 22 words at most
  • Each user_query starts with a short [label], then the instruction unchanged
Today
"objective": "Analyze AAPL, TSLA, and AMZN with a news summary, basic technical analysis (price trends, …), and a buy/hold/sell recommendation for each, then email the report to …"
"user_query": "Fetch the latest stock news (earnings reports, …"
With the addendum
"objective": "I'll pull the latest news, prices and indicators for AAPL, TSLA and AMZN, then email you the report."
"user_query": "[Gathering news, prices and indicators] Fetch the latest stock news (earnings reports, …"

Step executor

Writes step_output, the plugin calls JSON

  • Fixed key order per call, so a chip can be drawn before the parameters finish
  • Short parameters first (to, subject, symbol), long text last, so Outputs can title a draft at once
  • Never copy the [label] into a parameter
Already seen in the recording, now a rule
{"pluginId": "plugin-1722285968", "name": "sendEmail", …
 "api_request_parameters": {"to": "…", "subject": "Stock Analysis Report: …", "text": "<the long body, last>"}, …}

Answer

Writes fulfillment

  • Cite each external fact with a markdown link to the exact page the plugin returned. Sources and favicons are built from these links
  • Start with the result. The steps are already on screen
  • One “Data gap” sentence when a call failed
Close to this in the recording, now a rule
… the stock jumped about 5% ([CNBC](https://www.cnbc.com/2026/10/02/…), [Reuters](…))

**Data gap:** The Amazon news request failed because the data provider's rate limit was exceeded …

What is real and what is illustrative

  • Event names, fields, order and timings come from two runs recorded on 5 Oct 2026 in standard chat mode with claude-sonnet-5-5 at Low effort
  • Long texts are abridged. Most article links are shortened to the publisher's home page. The email address is a placeholder. The web-search answer body is placeholder text, since the answer area does not change
  • Rollout step 1 replays the frames as recorded. Step 2 rewrites only the objective and the step labels, as the planner addendum would. Step 3 puts a list of links at the front of the search response, as the wrapper change would
  • The replay runs on a thinned copy of each recording: 726 of the 1,033 frames and 203 of the 414, with the recorded timings, regenerated heartbeats and one search site left out
  • Logos and favicons on this page are drawn stand-ins. Production uses logoUrl and each site's own favicon, with a letter tile when none loads. The tile is also the air-gapped fallback
  • Reference patterns were checked live in ChatGPT and in Claude on 5 Oct 2026: one live line, steps that fold into “Worked for 2m 16s”, favicon chips, and a floating card on the right for outputs, sources and progress
